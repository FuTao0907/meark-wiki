## 通知的结构

一份标准的通知包含四个部分：

1. **标题**：发文机关 + 事由 + 文种（如《关于召开季度总结会的通知》）
2. **主送机关**：顶格写收文单位
3. **正文**：缘由 → 事项 → 要求
4. **落款**：发文机关 + 日期（加盖公章）

## 正文写法

### 缘由（为什么发）

交代背景、依据，常用句式：

- "为……，根据……，现将有关事项通知如下"
- "为进一步规范……，经研究决定……"

### 事项（通知什么）

分条列项，一事一条，用"一、二、三"或"（一）（二）（三）"。

### 要求（怎么做）

- 明确时间节点：请于 X 月 X 日前报送
- 明确责任人：由各部门负责人统筹
- 联系方式：联系人、电话、邮箱

## 常见错误

- 标题冗长、事由不清
- 主送机关漏写或错写
- 时间、地点、参会人员不齐全
- 语言口语化，缺乏公文感

## 参考句式库

- 会议通知："兹定于 X 月 X 日 X 时在 X 地召开 X 会议，现将有关事项通知如下"
- 放假通知："根据国家法定节假日安排，现将 X 年 X 节放假事宜通知如下"
- 制度通知："《X 管理办法》已经 X 审议通过，现予以印发，请遵照执行"
